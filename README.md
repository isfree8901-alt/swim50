# SWIM 50 종합 분석 (모바일 웹앱)

`index.html` 파일을 HTTPS 정적 호스팅(GitHub Pages 등)에 올리면 설치 없이 사용할 수 있습니다.

- Garmin Connect 개별 수영 활동의 **원본 내보내기**로 받은 `.fit`을 사용합니다. ZIP이면 해제 후 파일을 올리세요.
- FIT 파일은 브라우저 내부에서 해석되며 서버로 전송되지 않습니다.
- 지원: Garmin pool swim length 메시지 기반 활동. 다른 운동·일부 FIT 제조사 파일은 데이터가 없을 수 있습니다.
- 25m 길이별 영법·시간·스트로크, 정상 구간 필터(11~95초, 스트로크 3~60 등), 추이 및 규칙 기반 코칭.
- 평균 25m 구간은 워밍업, 드릴, 스프린트 등이 섞인 값이므로 공식 50m 경기 기록이나 독립된 25m PB로 해석하면 안 됩니다.
- Garmin SWOLF 값 자체 대신 구간 초 + 스트로크 수의 계산값을 표시합니다.
- 로컬스토리지 누적 데이터는 브라우저/기기별로 독립되므로 백업 및 복원을 이용하세요.
- 현재 앱의 규칙 분석은 정밀 스트로크 기술/수중 동작을 직접 관찰한 진단이 아닙니다.
- Garmin 공식 클라우드 자동 동기화, 로그인, 워치 실시간 연결은 포함하지 않습니다.

검증: 사용자 제공 `24727059112_ACTIVITY.fit` 파일로 내부 파서 실행 결과 총 1,650m, 25m 풀, length 메시지 119개(활성 66개), 초기 이상 구간 5개를 확인했습니다.
