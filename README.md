# SWIM 50 v3

모바일 중심 리디자인. `index.html`을 GitHub Pages 저장소 최상위에 업로드하세요. 기존 `swim50-pro-v1` 브라우저 저장 데이터를 그대로 사용합니다.

- 홈 / 기록·분석 / 훈련 3개 탭
- FIT 다중 선택, 중복 확인, 파일별 결과, 원본 구간 보기
- 대회 기록과 Garmin 훈련 기록 분리
- 25m, 주 2회, 회당 60분, 3영법 균등
- 맨몸 기본, 패들/킥판/풀부이/숏핀 선택
- JSON 백업/복원

기존 버전 데이터를 브라우저 캐시 정리 전에 반드시 JSON 백업하세요. 개인 브라우저 저장소의 용량 제약이 있습니다.

FIT 파서는 기존 SWIM 50 Pro 기반이며, Garmin 장치별 모든 FIT 필드 지원을 보장하지 않습니다. 서버/클라우드 동기화는 제공하지 않습니다.
