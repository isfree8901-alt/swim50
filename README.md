# SWIM 50 — 모바일 수영 스프린트 트래커

## 주요 기능
- 주 2회 DAY A / DAY B 훈련 루틴 진행 및 완료 내역 저장
- 자유형/배영/평영의 25m, 50m 기록 측정 이력
- 다이빙/벽 밀기 출발 분리, 50m 다이빙 기록 추이 그래프
- 50m 목표 수정, 스톱워치, 메모
- 데이터 JSON 내보내기/가져오기
- 모바일 반응형 화면 및 PWA 홈 화면 추가/오프라인 캐시

## 실행/공개
가장 간단한 사용 방법: `index.html`을 데스크톱 브라우저에서 실행해 기능을 확인합니다. 다만 파일 직접 열기(file://)는 iPhone에서 저장/설치 기능이 제한될 수 있습니다.

### GitHub Pages 배포
1. GitHub에서 새 **Public** 저장소를 생성합니다.
2. 이 폴더의 파일 4개(index.html, manifest.webmanifest, icon.svg, sw.js)를 저장소 최상위에 업로드합니다.
3. 저장소 Settings > Pages > Build and deployment에서 Deploy from a branch를 선택하고 main 및 /(root)를 지정한 뒤 저장합니다.
4. 발급된 HTTPS 주소를 휴대폰 Safari로 열고 공유 > 홈 화면에 추가를 선택합니다.

### 데이터 주의사항
- 기록은 현재 기기의 **해당 브라우저(localStorage)**에만 저장됩니다. 클라우드 자동 동기화/계정 기능은 없습니다.
- 브라우저 저장 데이터나 웹사이트 데이터 삭제 시 기록이 사라질 수 있습니다.
- 설정 > 전체 데이터 백업을 수시로 활용하고 다른 기기에서 백업 복원으로 옮길 수 있습니다.
- 임의의 공개 웹사이트에서 백업 파일을 업로드하지 마세요.

### 사전 설정
- 50m 다이빙 기준: 자유형 31초, 배영 36초, 평영 37초
- 8주 도전 목표: 29.9초 / 34.9초 / 35.9초 (추정 목표, 보장 아님)
- 25m 기록은 실측해 벽 밀기 출발로 입력하세요.
